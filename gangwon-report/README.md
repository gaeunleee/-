# 강원도 전시/체험 나라장터 입찰공고 수집 -> 엑셀

나라장터(조달청) 입찰공고정보서비스에서 **용역**·**공사** 공고를 2025-01-01 ~ 2026-12-31
기간 동안 15일 단위로 조회한 뒤, 강원 지역 + 전시/체험 관련 키워드 + 업종코드 조건에
맞는 건만 걸러 엑셀(`강원도_전시체험_협상계약_2025_2026.xlsx`)로 저장하는 1회성 스크립트입니다.

## ⚠️ 실행 전에 꼭 읽어주세요

1. **이 저장소(Claude Code 세션)에서는 apis.data.go.kr 접속이 네트워크 정책으로 막혀 있어
   제가 직접 실행해서 결과를 만들어 드릴 수 없었습니다.** 아래 두 방법 중 하나를 선택해주세요.
   - **(A) 사용자 PC/서버에서 직접 실행** — 아래 "실행 방법"대로 하시면 됩니다. 가장 간단합니다.
   - **(B) 이 세션의 네트워크 허용 목록에 apis.data.go.kr 추가** — claude.ai/code 환경 설정에서
     추가해주시면, 다음 메시지에서 제가 바로 이어서 실행해 결과 파일까지 만들어 드릴 수 있습니다.
2. **실제 응답 필드명은 테스트 호출로 확인하지 못했습니다.** `FIELD_CANDIDATES`에 공개 자료로
   교차검증한 후보 필드명을 넣어뒀지만(계약방법=`cntrctCnclsMthdNm`, 지역제한=`prtcptPsblRgnNm`
   등), 100% 확정은 아닙니다. **최초 실행 시 첫 응답의 실제 필드 키 목록을 콘솔에 출력**하도록
   만들어 뒀으니, 엑셀에 "계약방법"/"지역제한" 값이 비어 보이면 그 로그를 보고
   `fetch_and_build_report.py`의 `FIELD_CANDIDATES`에 실제 필드명을 추가해주세요.
3. **필터 조합(AND/OR)에 대한 안내**: "아래 조건 모두 만족"이라는 요청을 문자 그대로
   "지역 AND 키워드 AND 업종코드" 로 구현했습니다(`MATCH_MODE=AND`, 기본값). 다만 이 API들은
   용역/공사만 조회하므로 세부품명코드(물품 전용 필드)는 애초에 매칭될 수 없고, 업종코드도
   "투찰가능업종명" 텍스트에 실제로 값이 채워진 공고가 많지 않을 수 있어 AND 조건이 너무 엄격해
   결과가 매우 적거나 0건이 나올 수 있습니다. 스크립트는 실행 후 **조건별 건수(지역만/지역+키워드/
   지역+업종코드/AND/OR)를 콘솔에 함께 출력**하니, AND 결과가 너무 적으면 재호출 없이
   `MATCH_MODE=OR python fetch_and_build_report.py --skip-fetch` 로 즉시 재필터링해 비교해보세요.

## 실행 방법

```bash
cd gangwon-report
pip install -r requirements.txt

export NARA_SERVICE_KEY="발급받은 인증키(Decoding/평문 값)"
python fetch_and_build_report.py
```

- 15일 단위 창 49개 x 용역/공사 2개 오퍼레이션 = 약 98회 API 호출이 필요해 몇 분 정도 걸립니다.
- 호출 사이 0.4초씩 대기해 과다호출로 인한 차단을 피합니다.
- 중간에 실패하거나 중단돼도 `cache/progress.json`에 완료된 구간이 기록되어 있어, 같은 명령을
  다시 실행하면 **이미 받은 구간은 건너뛰고 이어서** 진행합니다.
- 결과: `output/강원도_전시체험_협상계약_2025_2026.xlsx`

캐시된 원본 데이터로 필터 조건만 바꿔 다시 만들고 싶을 때 (API 재호출 없음):

```bash
MATCH_MODE=OR python fetch_and_build_report.py --skip-fetch
```

## 인증키 보안

`NARA_SERVICE_KEY`는 환경변수로만 전달하며 어떤 파일에도 하드코딩하거나 커밋하지 않습니다.
`cache/`, `output/`, `.env`는 `.gitignore`에 포함되어 있어 실제 응답 데이터나 결과 파일이
실수로 git에 올라가지 않습니다.
