# 나라장터 입찰공고 자동 알림

주식회사 지일(강원 정선 본사, 경기 남양주 공장)의 경쟁입찰참가자격등록증을 기준으로
회사가 실제로 참가 가능한 입찰공고만 걸러서, 새 공고가 뜰 때마다 이메일로 알려주는
자동화입니다. GitHub Actions가 주기적으로 실행하므로 컴퓨터를 켜둘 필요가 없습니다.

## 필터 조건

- 공고명 키워드(하나 이상 포함): 전시, 체험, 제작설치, 전시관, 체험관, 콘텐츠, 미디어아트, 조성, 디자인, 도서관, 조형물
- 지역제한: 제한 없음(전국) 또는 "강원" 포함 또는 "경기" 포함
- 공사 공고: 추정가격 48억 3,500만원(실내건축공사업 시공능력평가액) 이하만
- 계약방법: 현재 제한 없음 (필요하면 `bid_alert.py`의 필터 로직에 추가 가능)

## 최초 설정 (한 번만 하면 됨)

1. **GitHub 저장소 Settings → Secrets and variables → Actions** 로 이동해서 아래 4개를 추가합니다.
   - `PPS_SERVICE_KEY` : 나라장터 오픈API 인증키
   - `GMAIL_ADDRESS` : 알림을 보낼 발신 Gmail 주소 (예: jayuna93@gmail.com)
   - `GMAIL_APP_PASSWORD` : Gmail "앱 비밀번호" (일반 로그인 비밀번호 아님 — 아래 참고)
   - `ALERT_TO` : 알림을 받을 이메일 주소 (발신 주소와 같아도 됨)

2. **Gmail 앱 비밀번호 만드는 법**
   - myaccount.google.com 접속 → 보안 → 2단계 인증을 먼저 켭니다 (필수).
   - 2단계 인증을 켠 뒤 "앱 비밀번호" 메뉴로 들어가서 새로 생성합니다.
   - 생성된 16자리 비밀번호를 `GMAIL_APP_PASSWORD` 시크릿에 붙여넣습니다.

3. 저장소의 **Actions** 탭에서 `나라장터 입찰공고 자동 알림` 워크플로를 확인하고,
   `Run workflow` 버튼으로 한 번 수동 실행해서 정상 동작하는지 확인합니다.

설정이 끝나면 이후로는 자동으로 3시간마다 새 공고를 확인하고, 조건에 맞는 새 공고가
있을 때만 이메일이 옵니다. (중복 알림 방지를 위해 이미 알림 보낸 공고는
`seen_bids.json`에 기록해두고 다시 보내지 않습니다.)

## 필드명 관련 참고사항

계약방법·지역제한 실제 API 필드명은 `cntrctCnclsMthdNm`, `prtcptPsblRgnNm` 등으로
가정하고 작성했습니다. 알림이 예상과 다르게 오거나 전혀 안 오면, 실제 응답 필드명이
다를 수 있으니 `narajangteo-alert/bid_alert.py`의 `CONTRACT_METHOD_FIELD_CANDIDATES`,
`REGION_FIELD_CANDIDATES` 부분을 실제 응답에 맞게 수정해야 합니다.
